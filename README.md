# 便當智慧點餐系統

獨立於其他儲存庫的 GitHub Pages + Google Apps Script + Google Sheets 點餐系統。

五款便當每款 NT$125：原味蒜香舒肥雞、韓式辣味舒肥雞胸、日式照燒舒肥雞胸、檸檬椒鹽舒肥雞胸、油蔥梅花豬。

## 系統

- Pages 提供固定點餐入口，Apps Script 提供顧客、店員、廚房與訂單查詢介面。
- 後端計價並驗證數量；每款最多20份，每單最多50份。
- 使用 ScriptLock 串行寫入，requestId 避免重試造成重複訂單。
- 顧客持有獨立查詢憑證；管理端需管理金鑰。金鑰保存在 Script Properties，不得提交至 GitHub。
- 訂單狀態：待接單 → 製作中 → 待取餐 → 已完成；待接單與製作中可取消。
- 廚房與查詢頁每5秒同步。現場付款，不含線上金流。

## 維護

Apps Script 原始碼：`backend/Code.gs`。修改後需更新 Apps Script Web App 部署版本。Google Sheets 是訂單儲存層，請勿改動 Orders 欄位次序。只分享給店內必要人員；不要公開訂單表或管理金鑰。

預設為小型單店流程；Apps Script / Sheets 配額、網路速度與瀏覽器儲存限制仍適用。顧客請保存訂單編號與查詢憑證。
